# 自分図書館

自分のPDFとメモを、このPCで読むためのWindows用の本棚です。無料・ログイン不要。PDFの見開き、横断検索、用語メモ、虫食い練習、完全バックアップを使えます。

[Windows版をダウンロード](https://github.com/ppuko1230/jibun-toshokan-releases/releases/latest/download/jibun-toshokan-windows.zip)

ZIPを右クリックして「すべて展開」し、中の **「自分図書館.exe」** を開いてください。初回の「使い始める」でデスクトップにアイコンを追加し、本棚を開きます。次回からはアイコンだけで使えます。外側はexe・使い方.txt・アプリ本体の3つです。「アプリ本体」は同じ場所に置いたまま使ってください。

最初の本棚は空です。教材・学習データは含みません。「PDFを追加」から自分の教材を入れられます。初回には操作する場所を明るく示す使い方ガイドが出ます。

すでに使っている方は、アプリの「設定 → アプリの更新 → 更新を確認」から更新できます。古い配布版の本棚を新しいZIPから引き継ぐ場合は、exeの初回画面で「以前の本棚を使っている方はこちら」を選び、今まで使っていた本棚のフォルダーを指定してください。教材やメモ、読書位置を保って更新します。個人版と配布版の更新は別です。

教材・メモはPC内に保存し、外部へ送信しません。通常の読書と保存はオフラインで利用できます。起動時の小さな更新通知と、利用者が選んだ更新の確認・ダウンロードの際にGitHubへ接続します。起動時の通知は設定でオフにできます。ダウンロードと適用は利用者が選んでから行います。

アプリ本体も止めたい場合は、すべての画面の編集を保存してから「設定 → アプリを終了する」を使えます。

同梱ソフトウェア・フォント・イラストのライセンスは配布物の `アプリ本体/THIRD-PARTY-NOTICES.txt` とアプリ設定から確認できます。このリポジトリは配布ファイルと案内の公開先です。教材や利用者のデータを投稿しないでください。
