# 自分図書館

自分のPDFとメモを、このPCで読むためのWindows用の本棚です。無料・ログイン不要。PDFの見開き、横断検索、用語メモ、虫食い練習、完全バックアップを使えます。

[Windows版をダウンロード](https://github.com/ppuko1230/jibun-toshokan-releases/releases/latest/download/jibun-toshokan-windows.zip)

ZIPをすべて展開し、「デスクトップに追加.cmd」を開いてください。最初の本棚は空です。教材・学習データは含みません。

初回以降はアプリの「設定 → アプリの更新 → 更新を確認」から更新できます。古い「余白」の配布版を使っている場合は、一度だけ新しいZIP内の「以前の本棚を更新.cmd」で引き継ぐと、その後はアプリ内で更新できます。個人版と配布版の更新は別です。

教材・メモはPC内に保存し、外部へ送信しません。通常の読書と保存はオフラインで利用できます。明示的な更新確認とダウンロードのときだけGitHubへ接続します。

同梱ソフトウェア・フォント・イラストのライセンスは配布物の `THIRD-PARTY-NOTICES.txt` とアプリ設定から確認できます。このリポジトリは配布ファイルと案内の公開先です。教材や利用者のデータを投稿しないでください。
